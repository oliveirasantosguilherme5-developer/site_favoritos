## 🚀 Como usar

Basta abrir o arquivo `index.html` no navegador, ou acessar via GitHub Pages.

## 📦 Tecnologias

- HTML5
- CSS3 (com animações e efeitos)
- JavaScript (partículas, efeito tilt, saudação dinâmica)
- [Font Awesome](https://fontawesome.com/) (ícones)
- [Google Fonts - Inter](https://fonts.google.com/specimen/Inter)

## 🌐 Deploy

Para publicar via GitHub Pages:
1. Faça push deste repositório para o GitHub
2. Vá em **Settings > Pages**
3. Selecione a branch `main` e clique em **Save**
4. O site ficará disponível em `https://oliveirasantosguilherme5.github.io/site_favoritos/`
